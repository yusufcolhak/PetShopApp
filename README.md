# PetShop Sipariş Yönetim Sistemi

Bu proje, bir PetShop için geliştirilmiş sipariş yönetim ve satış raporlama uygulamasıdır.

## Özellikler

- **Sipariş Girişi**: Müşteri bilgileri, evcil hayvan türü ve mama seçimi ile hızlı sipariş oluşturma.
- **Sipariş Takibi**: Tüm siparişleri listeleyen ve filtreleme imkanı sunan gelişmiş tablo görünümü.
- **Satış Raporları**: Günlük, haftalık ve aylık bazda satış performansını gösteren grafiksel raporlar.
- **Modern Arayüz**: Karanlık mod desteği ve kullanıcı dostu tasarım.

## Teknolojiler

- .NET 10.0
- Windows Forms (WinForms)
- C#
- JSON tabanlı veri depolama

## Kurulum ve Çalıştırma

1. Projeyi bilgisayarınıza indirin:
   ```bash
   git clone <repo-url>
   ```
2. Proje dizinine gidin:
   ```bash
   cd PROJE
   ```
3. Uygulamayı çalıştırın:
   ```bash
   dotnet run --project PetShopApp
   ```
